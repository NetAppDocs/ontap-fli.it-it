= Eseguire e monitorare l'importazione FLI LUN
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Dopo aver creato la relazione di importazione, si utilizza lun import start per avviare l'importazione in background dei dati dal LUN esterno nel LUN ONTAP di destinazione, e si monitora l'avanzamento con lun import show, che riporta l'operazione corrente (ad esempio import o verify), gli stati amministrativi e operativi e la percentuale di completamento, così da poter monitorare il job fino al completamento.

Negli scenari online in cui l'I/O dell'host e l'import competono per le stesse risorse di backend, è possibile eseguire temporaneamente lun import pause per interrompere il flusso di copia senza perdere i checkpoint, quindi lun import resume per continuare dall'ultimo checkpoint quando il carico e la latenza si stabilizzano; questo è un controllo consigliato per regolare i flussi di copia attivi mantenendo stabili i tempi di risposta dell'applicazione.

.Informazioni su questo compito
A partire da ONTAP 9.17.1, la migrazione dei dati di LUN esterne tramite migrazione offline FLI è supportata con i sistemi ASA r2. I sistemi ASA r2 si differenziano dagli altri sistemi ONTAP (ASA, AFF e FAS) per l'implementazione del proprio storage layer. Nei sistemi ASA r2, i volumi vengono creati automaticamente quando viene creata un'unità di storage (LUN o namespace). Ogni volume contiene solo una unità di storage. Pertanto, per i sistemi ASA r2, non è necessario includere il nome del volume nell'opzione  `-path` durante la creazione della LUN; è necessario invece includere il percorso dell'unità di storage.

.Fasi
. Imposta il livello di privilegio su advanced:
+
[source, cli]
----
set -privilege advanced
----
. Avviare l'importazione LUN:
+
[source, cli]
----
lun import start -vserver <SVM_NAME> -path /vol/<VOL>/<LUN_NAME>
----
. Monitora l'avanzamento dell'importazione:
+
[cols="2"]
|===
| Comando | Descrizione 


| Mostra tutte le importazioni su una SVM  a| 
[source, cli]
----
lun import show -vserver <SVM_NAME>
----


| Mostra un'importazione LUN specifica  a| 
[source, cli]
----
lun import show -vserver <SVM_NAME> -path /vol/<VOL>/<LUN_NAME>
----


| Visualizzazione dettagliata (include più campi)  a| 
[source, cli]
----
lun import show -instance
----
|===
. Se la latenza host è influenzata (controllo online comune), metti in pausa/riprendi:
+
[cols="2"]
|===
| Comando | Descrizione 


| Metti in pausa l'importazione (mantiene i checkpoint)  a| 
[source, cli]
----
lun import pause -vserver <SVM_NAME> -path /vol/<VOL>/<LUN_NAME>
----


| Conferma che è in pausa  a| 
[source, cli]
----
lun import show -vserver <SVM_NAME> -path /vol/<VOL>/<LUN_NAME>
----


| Riprendi l'importazione dall'ultimo checkpoint  a| 
[source, cli]
----
lun import resume -vserver <SVM_NAME> -path /vol/<VOL>/<LUN_NAME>
----


| Conferma che sia di nuovo in esecuzione  a| 
[source, cli]
----
lun import show -vserver <SVM_NAME> -path /vol/<VOL>/<LUN_NAME>
----
|===
