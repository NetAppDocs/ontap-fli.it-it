= Eseguire la correzione post-migrazione dell'host ONTAP FLI Solaris
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Dopo la migrazione, gli host Solaris richiedono passaggi di correzione per garantire che le LUN appena importate vengano riconosciute e funzionino correttamente.



== Post-migrazione - FLI offline

Per FLI offline, portare la LUN online dopo aver eliminato l'import della LUN e aver verificato che gli iSCSI initiator host siano connessi.

NOTE: Per l'elenco dei comandi più recente e aggiornato, consultare la documentazione del fornitore del sistema operativo.

.Fasi
. Eseguire una nuova scansione dopo l'attacco.
+
[source, cli]
----
cfgadm -al
----
. Identificare i dispositivi di archiviazione.
+
[source, cli]
----
format
sanlun lun show all
mpathadm list lu
mpathadm show lu
----
. Verificare che il dispositivo sia collegato.
+
[source, cli]
----
format |grep disk_id
----
. Importa lo zpool e FS verrà montato automaticamente.
+
[source, cli]
----
zpool import zpool_name
df -g (to ensure its unmounted)
----

Dopo aver eliminato l'importazione LUN, verificare se la LUN è configurata con -space-reserve disabilitato e -space-allocation abilitato. In caso contrario, modificarla di conseguenza.
